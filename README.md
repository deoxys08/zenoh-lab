# zenoh-lab

Hands-on notes for learning Eclipse Zenoh on a macOS laptop and two Raspberry Pi 5 boards.

| Step | Topic | Tag |
|------|-------|-----|
| 01 | Environment and network check | step-01 |
| 02 | Installation | step-02 |
| 03 | Peer-to-peer pub/sub | step-03 |
| 04 | Peer discovery (multicast scouting) | step-04 |
| 05 | zenohd router | step-05 |
| 06 | Client mode | step-06 |
| 07 | Query / Queryable | step-07 |
| 08 | Comparison with MQTT | step-08 |

## Topology
- Laptop (macOS): publisher / subscriber / query endpoints
- Pi-1: publisher / subscriber / queryable endpoints
- Pi-2: zenohd router
